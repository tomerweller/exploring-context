About UCMDB

HP Universal Configuration Management Database (UCMDB) software stores, controls, and manages software and infrastructure components along with associated relationships and dependencies. It provides unparalleled infrastructure visibility that shows how components are related for consistent and reliable delivery of IT and business services. This visibility improves and simplifies change control to avoid service disruptions and better track, manage and control IT infrastructures. HP UCMDB software reduces mean time to repair to keep operations running more efficiently.

My Role

In 2010 I began working with the UCMDB PCoE (Performance Center of Excellence) team as a student. The team's responsability is the overall performance of the group's products. It does so using the following methodology:

  1. Understand the client environment in which the product will run: IT capabilities, data characteristics, work load and most importantly, performance requirements.
  2. Build the tools needed to simulate this environment.
  3. Run a load simulation using these tools while monitoring performance.
  4. Find performance bottlenecks and get to the root cause in collaboration with the appropriate developers

I rigorously pushed for introduction of newer technologies and more emphasis on front end performance and perceived performance.
